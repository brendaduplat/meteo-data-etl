# Weather Data - Salvador, BA

Personal study project focused on collecting and analyzing weather data for Salvador, Bahia, using the OpenWeatherMap API for real-time data extraction.

## Credits

This project was inspired by [vbluuiza](https://youtu.be/I8qPqbXQBDU), whose [pipeline_etl_weather_data_tutorial_youtube](https://github.com/vbluuiza/pipeline_etl_weather_data_tutorial_youtube) served as a starting point. Several parts were modified for personal study and reasoning practice.

## About this project

This project is being built as a hands-on learning exercise in data engineering. The goal goes beyond having a working pipeline: it is to understand the fundamentals behind each practice, not just apply them, and to demonstrate that understanding through each step of the process (extract, transform, load) rather than copying pre-built solutions.

Commits are structured to reflect the learning process. Each commit generally corresponds to a concept or step being studied and applied, not just a finished feature. The commit history is meant to show progression, not just a final result.

## How to run

> **Note on current state**: during initial development, the API URL and key were used directly in the code to explore the response structure and understand the data before building the transform logic. Both have since been removed from the codebase. The API key will be loaded from a `.env` file, and the URL will be assembled and passed as part of the final pipeline flow (planned alongside the Airflow orchestration).

1. Clone the repository
2. Install dependencies: `uv sync`
3. *(Coming soon)* Create a `.env` file with your OpenWeatherMap API key 
4. *(Coming soon)* Run the full pipeline via Airflow
